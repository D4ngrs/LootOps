Categories now only show up where the name alone doesn't already say it — equipment gets the app's real TYPE / GRADE / CLASS / SIZE code (e.g. COOL / CIV / B / S2), wildlife trophies get their rarity Grade (AAA/AA/A/…), and plain commodities (Gold, Titanium, SLAM…) get nothing, since "Gold (Metal)" doesn't tell you anything "Gold" didn't. Quality is shown in gold too, same as the quality chip — teal isn't used here since it barely appears in the app itself (just focus rings and success messages). Commodities that ship in a box also show their SCU size. Multiples only show a count (3x) when someone actually won more than one of the same thing. Every row's item name, quantity, quality, and SCU are pulled from one shared item list rather than typed per-row, so the data stays internally consistent.
